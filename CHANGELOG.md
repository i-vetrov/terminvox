# Release notes

Each `## version` section below becomes the text of that GitHub release, and https://terminvox.dev/releases shows it.
`npm run release` refuses to run until the new version has a section here.

## 0.1.5

- Leaving a shell with `exit` or Ctrl+D now closes its tab and removes the terminal from the sidebar.
- New option to name a terminal when you create it: Settings, New terminals.

## 0.1.4

- Links in terminals are clickable: web links open in your browser, file paths open in Finder or your file manager.
- Trackpad scrolling in full-screen programs such as Claude Code now follows your fingers one row at a time.

## 0.1.3

- Changes pane: see the uncommitted git changes of the current terminal beside it (⌘G, or Ctrl+Shift+G on Windows and Linux).
- TerminVox now also runs on ARM64 Linux.
- The menu bar is gone on Windows and Linux.
- New app icon.

## 0.1.2

- Group startup script: commands that are typed once into each new terminal you create in a group, such as `cd ~/work/my-project`.

## 0.1.1

- Light mode, with a System, Light or Dark setting.
- Import your colors from macOS Terminal, Windows Terminal, Ghostty, kitty and Alacritty.

## 0.1.0

- First public release.
